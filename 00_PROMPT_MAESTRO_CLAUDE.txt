# PROMPT MAESTRO PARA CLAUDE — LANDING LAURA SÁNCHEZ COACH

Necesito que crees desde cero una landing completa para Laura Sánchez Coach.

La página actual existe solo como referencia de estructura y copy, pero este proyecto nuevo NO tiene componentes anteriores, NO tiene branding armado y NO tiene copy cargado. Tenés que construir todo desde cero, usando React/Vite, CSS responsive, GSAP y los assets locales indicados.

## Objetivo general

Crear una landing premium, minimalista y muy llamativa para vender/agendar una llamada de “Coaching de Alto Impacto” orientado a dueños de negocio, emprendedores y empresarios que son cuello de botella de su empresa.

Debe sentirse premium, minimalista, ejecutiva, moderna, elegante, clara, con CTAs fuertes, con mucho movimiento sofisticado y mucho mejor diseñada que la página actual. No debe sentirse infantil ni sobrecargada.

## Reglas importantes

- Hacer la página completa en una sola implementación.
- Crear todos los componentes necesarios.
- Mantener el copy separado del JSX en un archivo tipo `src/content/lauraCopy.js`.
- Mantener los datos de logos, estadísticas, situaciones, pasos, objetivos y FAQs en arrays/objetos reutilizables.
- No hardcodear todo dentro de JSX.
- Usar GSAP + ScrollTrigger para animaciones.
- Respetar `prefers-reduced-motion`.
- No usar emojis.
- No usar lorem ipsum ni placeholders.
- No finalizar hasta que compile correctamente.

## CTA

Todos los botones deben decir:

```txt
AGENDAR LLAMADA
```

Todos deben llevar con smooth scroll a la sección del calendario.

## Estilo visual base

Usar una estética minimalista premium:

- Fondo principal claro cálido/off-white.
- Secciones oscuras puntuales para contraste.
- Amarillo/dorado como color de acción.
- Tipografía display fuerte para títulos.
- Body muy legible.
- Botones grandes, muy visibles, con hover.
- Cards con bordes finos, sombras suaves, glow amarillo, y microinteracciones.
- Mucha animación de entrada con GSAP, pero elegante.

## Responsive

Mobile tiene que estar muy cuidado:

- Hero en una sola columna.
- Imagen de Laura como apoyo visual, no debe tapar el texto.
- CTAs centrados.
- Cards en 1 columna.
- Logos más chicos.
- Calendario usable.
- FAQ legible.
- Nada debe generar scroll horizontal.

## Validación final obligatoria

Al terminar ejecutar:

```bash
npm run lint
npm run build
```

Además revisar visualmente desktop, tablet y mobile. Validar que no haya scroll horizontal, que todos los botones scrolleen al calendario, que el calendario cargue, que el tracking externo esté cargado, que los 26 logos estén en el carrusel y que las imágenes de Laura se usen correctamente.
